# 使用指南

## 1. 启动服务

- 后端：`cd backend && python run.py`
- 前端：`cd frontend && npm run dev`

访问：`http://localhost:5173`

## 2. 开始录制

在首页（录制控制台）填写/选择：

- 保存规范（profile）：决定“采集/保存哪些字段、预设 URL 等”
- 起始 URL：默认空白页（空字符串）
- 浏览器：Chrome/Edge/Firefox
- 隐身模式：可选
- 用户数据目录：可选（用于保留登录状态；`incognito=false` 时才会生效）
- 窗口大小：预设或自定义

点击“开始录制”后会打开一个浏览器窗口。

## 3. 录制中

- 你在浏览器中的操作会被采集并通过 WebSocket 实时显示在“实时事件”列表中

## 4. 停止录制

- 点击“停止录制”：停止采集并保存（不会主动关闭浏览器）
- 直接关闭浏览器窗口/页面：会自动停止录制并保存

## 5. 查看数据

- 会话列表：查看所有录制会话（支持筛选/排序）
- 会话详情：查看事件详情、网络数据、截图（若启用）

## Profiles（保存规范）如何新增

1. 在 `backend/config/profiles/` 新建一个 `xxx.yaml`
2. 录制前在前端下拉框选择 `xxx`
3. 该 profile 会覆盖 `backend/config/recorder.yaml` 中的部分字段
