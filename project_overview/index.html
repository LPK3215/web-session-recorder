Web Session Recorder

基于 Playwright + FastAPI + Vue3 的浏览器会话录制工具

Playwright FastAPI Vue 3 WebSocket Pure File Storage

📋 项目简介

Web Session Recorder 通过 Playwright 自动化浏览器，注入捕获脚本记录用户交互事件（点击、输入、导航等）和网络请求，通过 WebSocket 实时推送到 Vue3 前端展示。所有数据以纯 JSON 和文件系统方式存储，便于频繁查看与备份。

🏗️ 架构全景

录制流程

  1. 前端调用 POST /api/sessions/start（携带 profile、url、browser、窗口大小）
  2. 后端创建 run_id 并创建 backend/runs/<run_id>/
  3. 启动浏览器并创建 context；导航到起始 URL
  4. 注入 injector.js，开始捕获事件 + 网络监控
  5. WebSocket 实时推送事件到前端
  6. 用户点击"停止录制"或关闭浏览器 → 停止采集并保存 session.json

🚀 快速开始

前置要求

  • ✅ Python 3.9+
  • ✅ Node.js 18+
  • ✅ Playwright 浏览器（运行 playwright install）

一键构建与启动（Windows）

Bat
:: 构建项目
build.bat

:: 启动前后端服务
start.bat

:: 前端: http://localhost:5173
:: 后端: http://localhost:8000

:: 停止服务
stop.bat

手动启动（开发模式）

Backend
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
playwright install
python run.py
Frontend
cd frontend
npm install
npm run dev
